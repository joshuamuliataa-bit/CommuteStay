# CommuteStay

**A destination-aware accommodation search and booking platform.**

CommuteStay is a web-based platform designed to help students, visitors and tourists find boarding houses and guesthouses in Lusaka, Zambia.

Unlike traditional accommodation platforms, CommuteStay focuses on **commute convenience**, allowing users to explore accommodation based on estimated travel times and routes to important destinations.

## Core Feature: Verified Route-Based Commute Estimates

CommuteStay integrates mapping and routing technology to help users understand how conveniently an accommodation property connects to their destination.

Users can:
- Select destinations such as Evelyn Hone College, NIPA and ZCAS University.
- View accommodation properties on an interactive map.
- Explore routes between properties and selected destinations.
- Compare route distances and estimated commute times.
- Make more informed accommodation decisions.

## Features

- Boarding house and guesthouse listings.
- Interactive maps.
- Destination-based accommodation search.
- Route-based commute-time estimation.
- Administrator-verified property listings.
- Property information and images.
- Accommodation booking functionality.
- Deposit-based booking concept.
